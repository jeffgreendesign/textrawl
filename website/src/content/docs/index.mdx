## Why Textrawl?

Give Claude access to your personal documents, emails, notes, and knowledge. Textrawl combines **semantic understanding** with **keyword precision** using Reciprocal Rank Fusion to deliver the most relevant results.

  <Card title="Hybrid Search" icon="magnifier">

## Quick Start

```bash
# Clone and setup
git clone https://github.com/jeffgreendesign/textrawl.git
cd textrawl
npm run setup

# Start the server
npm run dev

# Test with MCP Inspector
npm run inspector
```

## MCP Tools

Textrawl exposes 5 tools via MCP:

| Tool | Purpose |
|------|---------|
| `search_knowledge` | Hybrid search with configurable weights |
| `get_document` | Retrieve full document content |
| `list_documents` | Browse documents with pagination |
| `update_document` | Update document title and tags |
| `add_note` | Create notes with automatic embedding |

[View all tools →](/mcp-tools/overview/)

## Architecture

```
┌─────────────────────────────────────────────────────────┐
│                    Claude Desktop                        │
│                    or Cursor IDE                         │
└────────────────────────┬────────────────────────────────┘
                         │ MCP Protocol
                         ▼
┌─────────────────────────────────────────────────────────┐
│                    Textrawl Server                       │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────┐  │
│  │   Search    │  │  Documents  │  │     Notes       │  │
│  │  (Hybrid)   │  │  (CRUD)     │  │  (Add + Embed)  │  │
│  └──────┬──────┘  └──────┬──────┘  └────────┬────────┘  │
│         │                │                   │           │
│         └────────────────┼───────────────────┘           │
│                          ▼                               │
│  ┌─────────────────────────────────────────────────────┐│
│  │           Supabase PostgreSQL + pgvector            ││
│  │  • documents (full-text search)                     ││
│  │  • chunks (vector embeddings)                       ││
│  │  • hybrid_search() RPC                              ││
│  └─────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────┘
```
