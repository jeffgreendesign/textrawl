Build the Textrawl desktop application from source for development or custom builds.

## Prerequisites

- Node.js 22+
- npm 10+
- Platform-specific build tools (see below)

### macOS

```bash
# Install Xcode command line tools
xcode-select --install
```

### Windows

```bash
# Install Visual Studio Build Tools
npm install --global windows-build-tools
```

### Linux

```bash
# Debian/Ubuntu
sudo apt-get install build-essential

# Fedora
sudo dnf install make automake gcc gcc-c++
```

## Quick Start

```bash
# From repository root
cd desktop

# Install dependencies
npm install

# Start development mode
npm run dev
```

This starts:
- Vite dev server for the renderer (hot reload)
- Electron main process
- Preload script watcher

## Development

### Start Dev Mode

```bash
npm run dev
```

Opens Electron with hot reload for the renderer process.

### Main Process Changes

Changes to `src/main/` require app restart:

```bash
# Stop current instance (Ctrl+C)
npm run dev
```

### Renderer Changes

Changes to `src/renderer/` hot reload automatically.

## Building

### Development Build

```bash
npm run build
```

Creates unpackaged build in `dist/`.

### Production Build

## Configuration

### electron-builder.yml

```yaml
appId: com.textrawl.app
productName: Textrawl
directories:
  output: dist
  buildResources: build
files:
  - dist/**/*
  - package.json
mac:
  category: public.app-category.productivity
  target:
    - dmg
    - zip
win:
  target:
    - nsis
linux:
  target:
    - AppImage
    - deb
```

### Code Signing (macOS)

For distribution outside the Mac App Store:

```bash
export CSC_LINK=path/to/certificate.p12
export CSC_KEY_PASSWORD=your-password
npm run build:mac
```

### Windows Signing

```bash
export WIN_CSC_LINK=path/to/certificate.pfx
export WIN_CSC_KEY_PASSWORD=your-password
npm run build:win
```

## Troubleshooting

### "Cannot find module" errors

```bash
# Clean install
rm -rf node_modules
npm install
```

### Build fails on macOS

Ensure Xcode tools are installed:

```bash
xcode-select --install
```

### Native module errors

Rebuild for Electron:

```bash
npm run rebuild
```

### Window doesn't appear

Check for errors in terminal. Enable DevTools:

```typescript
// src/main/index.ts
win.webContents.openDevTools();
```
