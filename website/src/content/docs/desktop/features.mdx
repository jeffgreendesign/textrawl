Textrawl includes an Electron desktop application for drag-and-drop file conversion with a native interface.

## Overview

The desktop app provides:

- **Native UI**: Platform-specific look and feel
- **Drag-and-drop**: Convert files by dropping them onto the window
- **Real-time progress**: Watch conversion happen live
- **Direct upload**: Send to Supabase after conversion
- **Persistent settings**: Remembers your preferences

## Supported Formats

| Format | Extensions | Description |
|--------|------------|-------------|
| Email | `.mbox`, `.eml` | Email archives and individual messages |
| Documents | `.pdf`, `.docx`, `.txt`, `.md` | Common document formats |
| Spreadsheets | `.xlsx` | Excel files (text extraction) |
| Presentations | `.pptx` | PowerPoint slides |
| Web | `.html`, `.htm` | Saved web pages |
| Archives | `.zip` | Google Takeout exports |

## Features

### Batch Processing

Drop multiple files or folders at once:

1. Select files in Finder/Explorer
2. Drag onto the Textrawl window
3. Watch progress for each file
4. Upload when ready

### Conversion Options

Access via Settings button:

- **Output directory**: Where to save converted files
- **Date folders**: Organize emails by month
- **Clean boilerplate**: Remove navigation from HTML
- **Extract attachments**: Save email attachments

### Upload Integration

After conversion:

1. Click "Upload All" or select individual files
2. Progress bar shows embedding generation
3. Success indicators when complete
4. Files tracked in manifest to prevent duplicates

### Settings Persistence

Configuration stored via `electron-store`:

- Supabase credentials
- Embedding provider choice
- Output directory preference
- UI theme (light/dark)

Settings survive app restarts and updates.
