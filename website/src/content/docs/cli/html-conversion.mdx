title: HTML Conversion
description: Convert web pages to searchable markdown
---

Convert HTML files to Markdown with automatic metadata extraction and boilerplate removal.

## Usage

```bash
npm run convert -- html <path> [options]
```

## Examples

```bash
# Single file
npm run convert -- html page.html

# Directory of HTML files
npm run convert -- html ./saved-pages/

# Recursive with boilerplate removal
npm run convert -- html ./saved-pages/ -r --clean-boilerplate

# With base URL for relative links
npm run convert -- html article.html --url-base "https://example.com"
```

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `-o, --output <dir>` | `./converted/web` | Output directory |
| `-r, --recursive` | `false` | Process directories recursively |
| `--clean-boilerplate` | `true` | Remove nav, footer, ads, etc. |
| `--extract-images` | `false` | Extract and save images |
| `--url-base <url>` | - | Base URL for relative links |
| `--raw` | `false` | Preserve raw text |

## Output Structure

```
./converted/web/
├── article-title.md
├── page-two.md
└── images/
    ├── image-1.png
    └── image-2.jpg
```

## Boilerplate Removal

With `--clean-boilerplate` (default), Textrawl removes:

- Navigation menus
- Footers
- Sidebars
- Advertisements
- Cookie banners
- Social sharing buttons

This keeps only the main content for cleaner search results.

```bash
# Keep all HTML content
npm run convert -- html page.html --no-clean-boilerplate
```

## Handling Images

### Extract and Save

```bash
npm run convert -- html article.html --extract-images
```

Creates:

```
./converted/web/
├── article.md
└── article_images/
    ├── figure-1.png
    └── diagram.svg
```

Images are referenced in markdown:

```markdown
![Figure 1](article_images/figure-1.png)
```

### Keep Original URLs

Without `--extract-images`, image URLs are preserved:

```markdown
![Figure 1](https://example.com/images/figure-1.png)
```

## Processing Directories

### Flat Processing

Process only immediate children:

```bash
npm run convert -- html ./saved-pages/
```

### Recursive Processing

Process all subdirectories:

```bash
npm run convert -- html ./saved-pages/ -r
```

Maintains directory structure:

```
./saved-pages/
├── blog/
│   └── post.html
└── docs/
    └── guide.html

→ converted to:

./converted/web/
├── blog/
│   └── post.md
└── docs/
    └── guide.md
```

## Metadata Extraction

Textrawl extracts metadata from:

- `<title>` tag
- `<meta name="author">`
- `<meta name="description">`
- `<meta property="og:*">` (Open Graph)
- `<meta name="article:*">` (Article metadata)
- `<time>` elements (publication date)

## Best Practices

1. **Use clean-boilerplate**: Removes noise for better search (default)

2. **Set url-base for saved pages**: Fixes relative links
   ```bash
   npm run convert -- html offline.html --url-base "https://original-site.com"
   ```

3. **Extract images for offline archives**: Ensures images are preserved
   ```bash
   npm run convert -- html archive/ -r --extract-images
   ```

4. **Add source tags**: Organize by origin
   ```bash
   npm run convert -- html ./tech-blog/ --tags tech blog
   ```

## Common Sources

### Saved Browser Pages

Most browsers save as `.html`:

```bash
npm run convert -- html ~/Downloads/*.html
```

### Wget Archives

Convert wget mirror sites:

```bash
npm run convert -- html ./mirror-site/ -r --url-base "https://original.com"
```

### SingleFile Extensions

Browser extensions like SingleFile save complete pages:

```bash
npm run convert -- html ./singlefile-saves/ --extract-images
```

## Troubleshooting

### Empty output

Check if the HTML has JavaScript-rendered content. Static conversion doesn't execute JavaScript.

### Encoding issues

Specify encoding if auto-detection fails:

```bash
npm run convert -- html page.html -v
```

### Missing content

Try disabling boilerplate removal:

```bash
npm run convert -- html page.html --no-clean-boilerplate
```
