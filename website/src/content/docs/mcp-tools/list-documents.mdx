---
title: list_documents
description: Browse documents with pagination and filtering
---

List documents in the knowledge base with pagination and optional filtering by source type or tags.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `limit` | number | No | 20 | Documents per page (1-100) |
| `offset` | number | No | 0 | Pagination offset |
| `sourceType` | enum | No | - | Filter by source: `note`, `file`, or `url` |
| `tags` | string[] | No | - | Filter to docs with ALL specified tags |

## Example Request

```json
{
  "limit": 10,
  "offset": 0,
  "sourceType": "note",
  "tags": ["work"]
}
```

## Response Fields

### Document Object

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Document unique identifier |
| `title` | string | Document title |
| `sourceType` | enum | `note`, `file`, or `url` |
| `tags` | string[] | Document tags |
| `createdAt` | ISO 8601 | Creation timestamp |
| `updatedAt` | ISO 8601 | Last update timestamp |

### Pagination Object

| Field | Type | Description |
|-------|------|-------------|
| `limit` | number | Documents per page |
| `offset` | number | Current offset |
| `total` | number | Total document count |
| `hasMore` | boolean | More pages available |

## Filtering

### By Source Type

| sourceType | Description |
|------------|-------------|
| `note` | Created via `add_note` tool |
| `file` | Uploaded via CLI or Web UI |
| `url` | Web content (future feature) |

```json
{
  "sourceType": "file",
  "limit": 20
}
```

### By Tags

Filter to documents containing ALL specified tags:

```json
{
  "tags": ["project-x", "2025"],
  "limit": 50
}
```

Returns only documents tagged with both `project-x` AND `2025`.

## Pagination

### Getting All Pages

```javascript
let offset = 0;
const limit = 100;
let allDocuments = [];

while (true) {
  const result = await listDocuments({ limit, offset });
  allDocuments.push(...result.documents);

  if (!result.pagination.hasMore) break;
  offset += limit;
}
```

### Page Navigation

```text
Page 1: offset = 0,  limit = 20  (items 1-20)
Page 2: offset = 20, limit = 20  (items 21-40)
Page 3: offset = 40, limit = 20  (items 41-60)
```

## Use Cases

### Browse All Documents

```json
{
  "limit": 50
}
```

### Find Recent Notes

```json
{
  "sourceType": "note",
  "limit": 10
}
```

Documents are returned in reverse chronological order (newest first).

### Filter by Project

```json
{
  "tags": ["project-alpha"],
  "limit": 100
}
```

### Audit Uploaded Files

```json
{
  "sourceType": "file",
  "limit": 100
}
```

## Best Practices

1. **Use pagination**: Don't request all documents at once for large knowledge bases
2. **Combine filters**: Use both `sourceType` and `tags` for precise results
3. **Check hasMore**: Always check pagination to know if more results exist
4. **Get details separately**: Use `get_document` for full content of specific items
