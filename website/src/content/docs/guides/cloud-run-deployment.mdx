Deploy Textrawl as a serverless container on Google Cloud Run.

## Prerequisites

- Google Cloud account with billing enabled
- [gcloud CLI](https://cloud.google.com/sdk/docs/install) installed
- Docker installed locally

## Quick Deploy

```bash
# Set your project
export GCP_PROJECT_ID=your-project-id
export GCP_REGION=us-central1

# Deploy
./scripts/deploy.sh
```

## Step-by-Step

<Steps>

1. **Configure gcloud**

   ```bash
   gcloud auth login
   gcloud config set project YOUR_PROJECT_ID
   gcloud services enable run.googleapis.com artifactregistry.googleapis.com
   ```

2. **Create Artifact Registry**

   ```bash
   gcloud artifacts repositories create textrawl \
     --repository-format=docker \
     --location=us-central1
   ```

3. **Store secrets**

   ```bash
   # Create secrets
   echo -n "your-supabase-url" | gcloud secrets create SUPABASE_URL --data-file=-
   echo -n "your-service-key" | gcloud secrets create SUPABASE_SERVICE_KEY --data-file=-
   echo -n "your-openai-key" | gcloud secrets create OPENAI_API_KEY --data-file=-
   echo -n "your-api-token" | gcloud secrets create API_BEARER_TOKEN --data-file=-
   ```

4. **Build and push image**

   ```bash
   # Configure Docker for Artifact Registry
   gcloud auth configure-docker us-central1-docker.pkg.dev

   # Build and push
   docker build -t us-central1-docker.pkg.dev/$GCP_PROJECT_ID/textrawl/textrawl:latest .
   docker push us-central1-docker.pkg.dev/$GCP_PROJECT_ID/textrawl/textrawl:latest
   ```

5. **Deploy to Cloud Run**

   ```bash
   gcloud run deploy textrawl \
     --image us-central1-docker.pkg.dev/$GCP_PROJECT_ID/textrawl/textrawl:latest \
     --region us-central1 \
     --memory 512Mi \
     --cpu 1 \
     --min-instances 0 \
     --max-instances 10 \
     --set-secrets "SUPABASE_URL=SUPABASE_URL:latest,SUPABASE_SERVICE_KEY=SUPABASE_SERVICE_KEY:latest,OPENAI_API_KEY=OPENAI_API_KEY:latest,API_BEARER_TOKEN=API_BEARER_TOKEN:latest" \
     --allow-unauthenticated
   ```

</Steps>

## Deploy Script

The included `scripts/deploy.sh` automates the above:

```bash
#!/bin/bash
set -e

PROJECT_ID=${GCP_PROJECT_ID:?"Set GCP_PROJECT_ID"}
REGION=${GCP_REGION:-us-central1}
IMAGE="$REGION-docker.pkg.dev/$PROJECT_ID/textrawl/textrawl:latest"

# Build and push
docker build -t $IMAGE .
docker push $IMAGE

# Deploy
gcloud run deploy textrawl \
  --image $IMAGE \
  --region $REGION \
  --memory 512Mi \
  --cpu 1 \
  --min-instances 0 \
  --max-instances 10 \
  --set-secrets "SUPABASE_URL=SUPABASE_URL:latest,SUPABASE_SERVICE_KEY=SUPABASE_SERVICE_KEY:latest,OPENAI_API_KEY=OPENAI_API_KEY:latest,API_BEARER_TOKEN=API_BEARER_TOKEN:latest" \
  --allow-unauthenticated
```

## Configuration

### Resource Allocation

| Setting | Value | Notes |
|---------|-------|-------|
| Memory | 512Mi | Minimum for embedding generation |
| CPU | 1 | Sufficient for typical workloads |
| Min instances | 0 | Scale to zero when idle |
| Max instances | 10 | Adjust based on load |

<Aside type="tip">
  Start with min-instances=0 to minimize costs. Set min-instances=1 to eliminate cold starts.
</Aside>

### Concurrency

```bash
gcloud run deploy textrawl \
  --concurrency 80 \
  ...
```

Higher concurrency = fewer instances needed, but more memory per instance.

### Custom Domain

```bash
gcloud run domain-mappings create \
  --service textrawl \
  --domain textrawl.yourdomain.com \
  --region us-central1
```

Then configure DNS as instructed.

## Connecting Claude

After deployment, get your service URL:

```bash
gcloud run services describe textrawl --region us-central1 --format 'value(status.url)'
# Example: https://textrawl-abc123-uc.a.run.app
```

Configure Claude Desktop:

```json
{
  "mcpServers": {
    "textrawl": {
      "url": "https://textrawl-abc123-uc.a.run.app/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_BEARER_TOKEN"
      }
    }
  }
}
```

## Cost Optimization

### Scale to Zero

```bash
--min-instances 0
```

Only pay when requests come in.

### CPU Throttling

```bash
--cpu-throttling
```

Reduce CPU between requests (lower cost, higher cold start).

### Regional Pricing

`us-central1` and `us-east1` are typically cheapest.

## Troubleshooting

### Cold Start Latency

Symptoms: First request after idle is slow (5-10s)

Solutions:
- Set `--min-instances 1`
- Reduce container size
- Optimize startup code

### Out of Memory

Symptoms: Container crashes, restarts

Solutions:
- Increase `--memory` to 1Gi or 2Gi
- Reduce `--concurrency`
- Check for memory leaks

### Secret Access Denied

```bash
# Grant access to service account
gcloud secrets add-iam-policy-binding SUPABASE_URL \
  --member="serviceAccount:$PROJECT_NUMBER-compute@developer.gserviceaccount.com" \
  --role="roles/secretmanager.secretAccessor"
```

### Container Fails Health Check

Check logs for startup errors:
```bash
gcloud run logs read textrawl --region us-central1
```
