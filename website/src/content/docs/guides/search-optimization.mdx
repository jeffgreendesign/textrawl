Tips and techniques for getting the most relevant results from Textrawl's hybrid search.

## Understanding Hybrid Search

Textrawl combines two search strategies:

| Strategy | Strength | Weakness |
|----------|----------|----------|
| **Full-Text** | Exact keywords, names, codes | Misses synonyms, paraphrases |
| **Semantic** | Meaning, concepts, questions | May miss exact terms |

**Reciprocal Rank Fusion (RRF)** combines both, giving you the best of both worlds.

## Tuning Search Weights

### Default Weights (Balanced)

```json
{
  "query": "project planning",
  "fullTextWeight": 1.0,
  "semanticWeight": 1.0
}
```

### Keyword-Heavy (Names, Codes, IDs)

For specific identifiers that must match exactly:

```json
{
  "query": "PRJ-12345",
  "fullTextWeight": 1.5,
  "semanticWeight": 0.5
}
```

### Semantic-Heavy (Questions, Concepts)

For natural language questions about meaning:

```json
{
  "query": "how does our authentication system work",
  "fullTextWeight": 0.5,
  "semanticWeight": 1.5
}
```

### Pure Keyword

When you know the exact term:

```json
{
  "query": "error code 503",
  "fullTextWeight": 2.0,
  "semanticWeight": 0
}
```

### Pure Semantic

For exploratory, concept-based search:

```json
{
  "query": "documents about improving team collaboration",
  "fullTextWeight": 0,
  "semanticWeight": 2.0
}
```

## Query Strategies

### Be Specific

❌ `"meeting notes"`
✅ `"Q4 planning meeting notes with marketing team"`

### Include Context

❌ `"budget"`
✅ `"2024 marketing budget approval"`

### Use Natural Language for Semantic

❌ `"error database"`
✅ `"why am I getting database connection errors"`

### Use Exact Terms for Full-Text

❌ `"problems with the login"`
✅ `"AuthenticationError login failed"`

## Filtering Strategies

### Combine Tags with Search

Narrow results before search:

```json
{
  "query": "quarterly results",
  "tags": ["finance", "2024"]
}
```

### Use Source Types

Focus on specific document types:

```json
{
  "query": "deployment process",
  "sourceType": "note"
}
```

### Set Minimum Score

Filter out weak matches:

```json
{
  "query": "specific topic",
  "minScore": 0.7
}
```

<Aside type="caution">
  High `minScore` thresholds may exclude relevant results. Start low (0.5) and increase if needed.
</Aside>

## Organizing for Better Search

### Use Consistent Tags

Create a tagging taxonomy:

```
project-x, project-y    # Projects
2024-q1, 2024-q2       # Time periods
meeting, email, doc    # Document types
important, archived    # Status
```

### Write Descriptive Titles

Titles are heavily weighted in full-text search:

❌ `"Notes"`
✅ `"Q4 2024 Marketing Strategy Planning Session Notes"`

### Structure Content with Headings

Headings create better chunk boundaries:

```markdown
# Project Status Update

## Completed Items
- Item 1
- Item 2

## In Progress
- Item 3

## Blockers
- Issue description
```

### Include Keywords Naturally

Ensure important terms appear in the text:

❌ `"We discussed the thing and made decisions."`
✅ `"We discussed the Q4 marketing budget and decided to increase digital ad spend by 20%."`

## Troubleshooting Poor Results

### No Results

1. Check if documents exist:
   ```json
   { "limit": 10 }  // list_documents
   ```

2. Try broader query:
   ```json
   { "query": "planning", "limit": 20 }
   ```

3. Remove filters:
   ```json
   { "query": "planning" }  // No tags, sourceType, minScore
   ```

### Too Many Irrelevant Results

1. Add filters:
   ```json
   { "query": "planning", "tags": ["2024"] }
   ```

2. Increase minimum score:
   ```json
   { "query": "planning", "minScore": 0.6 }
   ```

3. Be more specific in query:
   ```json
   { "query": "Q4 2024 product roadmap planning session" }
   ```

### Missing Known Documents

1. Check document exists and has expected tags
2. Verify the content contains your search terms
3. Try searching with known unique words from the document
4. Check if document was uploaded after knowledge base initialization

## Search Patterns

### Pattern: Find and Expand

Start narrow, then expand:

```text
1. search_knowledge(query: "specific term", limit: 3)
   → Get initial results

2. get_document(documentId: result.documentId)
   → Get full context

3. Use document keywords to search again
   search_knowledge(query: "related terms from document")
```

### Pattern: Multi-Faceted Search

Search the same concept different ways:

```text
1. search_knowledge(query: "user authentication")
2. search_knowledge(query: "login security")
3. search_knowledge(query: "how do users sign in")
```

### Pattern: Progressive Refinement

Narrow down iteratively:

```text
1. search_knowledge(query: "budget", limit: 20)
   → 20 results, too broad

2. search_knowledge(query: "marketing budget", limit: 10)
   → 10 results, getting closer

3. search_knowledge(query: "2024 Q4 marketing budget approval", tags: ["finance"])
   → 2 results, perfect
```
