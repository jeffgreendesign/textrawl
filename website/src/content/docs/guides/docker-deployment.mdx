Deploy Textrawl using Docker for production or local development.

## Quick Start

```bash
# Clone repository
git clone https://github.com/jeffgreendesign/textrawl.git
cd textrawl

# Configure environment
cp .env.example .env
# Edit .env with your credentials

# Start with Docker Compose
docker compose up -d
```

## Docker Compose

### Production Stack

`docker-compose.yml` provides a production-ready configuration:

```yaml
services:
  textrawl:
    build: .
    ports:
      - "8080:8080"
    environment:
      - SUPABASE_URL=${SUPABASE_URL}
      - SUPABASE_SERVICE_KEY=${SUPABASE_SERVICE_KEY}
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - API_BEARER_TOKEN=${API_BEARER_TOKEN}
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080/health/live"]
      interval: 30s
      timeout: 10s
      retries: 3
```

```bash
# Start
docker compose up -d

# View logs
docker compose logs -f

# Stop
docker compose down
```

### Local Development Stack

`docker-compose.local.yml` includes PostgreSQL and Ollama for fully local development:

```bash
# Start PostgreSQL with pgvector
docker compose -f docker-compose.local.yml up -d

# Add Ollama for local embeddings
docker compose -f docker-compose.local.yml --profile ollama up -d

# Add pgAdmin for database management
docker compose -f docker-compose.local.yml --profile admin up -d
```

**Services:**

| Service | Port | Description |
|---------|------|-------------|
| postgres | 5432 | PostgreSQL with pgvector |
| ollama | 11434 | Local embedding generation |
| pgadmin | 5050 | Database admin UI |

## Dockerfile

The multi-stage Dockerfile optimizes for production:

```dockerfile
# Build stage
FROM node:22-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# Production stage
FROM gcr.io/distroless/nodejs22-debian12
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/package.json ./
EXPOSE 8080
CMD ["dist/index.js"]
```

**Key features:**
- Multi-stage build reduces image size
- Distroless base for security
- Only production dependencies included
- Exposed on port 8080

## Building the Image

```bash
# Build locally
docker build -t textrawl .

# Build with specific platform
docker build --platform linux/amd64 -t textrawl .

# Run the image
docker run -p 8080:8080 --env-file .env textrawl
```

## Health Checks

The container exposes health endpoints:

| Endpoint | Description |
|----------|-------------|
| `/health/live` | Container is running |
| `/health/ready` | Database connected, ready for traffic |
| `/health` | Basic status |

```bash
# Check health
curl http://localhost:8080/health/ready
```

## Volumes

For persistent data with local PostgreSQL:

```yaml
volumes:
  postgres_data:
    driver: local

services:
  postgres:
    volumes:
      - postgres_data:/var/lib/postgresql/data
```

## Networking

### Expose to Host

```yaml
ports:
  - "8080:8080"  # host:container
```

### Internal Only

```yaml
expose:
  - "8080"  # Only accessible to other containers
```

### Custom Network

```yaml
networks:
  textrawl-network:
    driver: bridge

services:
  textrawl:
    networks:
      - textrawl-network
```

## Production Considerations

### Resource Limits

```yaml
services:
  textrawl:
    deploy:
      resources:
        limits:
          cpus: '1'
          memory: 512M
        reservations:
          cpus: '0.5'
          memory: 256M
```

### Logging

```yaml
services:
  textrawl:
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"
```

### Restart Policy

```yaml
services:
  textrawl:
    restart: unless-stopped
```

## Troubleshooting

### Container won't start

Check logs:
```bash
docker compose logs textrawl
```

### Database connection fails

Verify Supabase credentials:
```bash
docker compose exec textrawl env | grep SUPABASE
```

### Out of memory

Increase container memory limits or reduce concurrency in upload operations.

### Health check failing

Check if dependencies are ready:
```bash
docker compose exec textrawl curl http://localhost:8080/health/ready
```
