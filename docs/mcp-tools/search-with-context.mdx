---
title: search_with_context
description: Unified search across documents, memories, and conversations
---

Search across all knowledge sources simultaneously with configurable weights per source type.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `query` | string | REQUIRED | - | Search query (1-10000 chars) |
| `limit` | number | OPTIONAL | `5` | Max results per source (1-30) |
| `includeDocuments` | boolean | OPTIONAL | `true` | Search documents/notes |
| `includeMemories` | boolean | OPTIONAL | `true` | Search entity memories |
| `includeConversations` | boolean | OPTIONAL | `false` | Search past conversations |
| `documentWeight` | number | OPTIONAL | `1.0` | Weight for document results (0-2) |
| `memoryWeight` | number | OPTIONAL | `1.0` | Weight for memory results (0-2) |
| `conversationWeight` | number | OPTIONAL | `0.5` | Weight for conversation results (0-2) |

## Example Request

```json
{
  "query": "database architecture decisions",
  "includeDocuments": true,
  "includeMemories": true,
  "includeConversations": true,
  "limit": 5
}
```

## Use Cases

### Comprehensive Context Gathering

Search everything at once before answering a question:

```json
{
  "query": "user preferences and project requirements",
  "includeConversations": true,
  "memoryWeight": 1.5
}
```

### Document-Only Search

Equivalent to `search_knowledge` but through the unified interface:

```json
{
  "query": "deployment guide",
  "includeMemories": false,
  "includeConversations": false
}
```

## Related Tools

- `search_knowledge` - Document-only hybrid search with RRF weights
- `recall_memories` - Memory-only search
