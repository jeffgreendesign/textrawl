---
title: list_conversations
description: List recent conversation sessions
---

Browse conversation sessions with pagination.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `limit` | number | OPTIONAL | `20` | Max results (1-50) |
| `offset` | number | OPTIONAL | `0` | Pagination offset |

## Example Request

```json
{ "limit": 10 }
```

## Related Tools

- `get_conversation` - Get full conversation transcript
- `recall_conversation` - Search conversations semantically
- `delete_conversation` - Delete a conversation
