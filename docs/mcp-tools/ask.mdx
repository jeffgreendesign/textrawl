Search across all your knowledge — documents, memories, conversations, and insights — with a single natural language question. Returns structured results with citations. This is the recommended entry point for querying Textrawl.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `question` | string | Yes | - | Natural language question to search your knowledge base (1-10000 chars) |
| `scope` | enum | No | `auto` | Which sources to search: `auto`, `documents`, `memory`, `conversations`, `insights` |
| `limit` | number | No | `10` | Maximum results per source (1-50) |

## Example Request

### Auto Scope (Default)

```json
{
  "question": "What did we decide about the migration strategy?"
}
```

### Scoped to Documents

```json
{
  "question": "API rate limiting best practices",
  "scope": "documents",
  "limit": 5
}
```

### Scoped to Memory

```json
{
  "question": "What do I know about Alice's role?",
  "scope": "memory",
  "limit": 20
}
```

## Notes

- This tool is **read-only** and **idempotent** — it does not modify any data.
- When `scope` is set to `auto`, Textrawl determines which sources are most relevant to the question and searches them automatically.
- Results include citations back to the original source, making it easy to verify or dive deeper.
- For more control over search weights and filtering, use the [`search`](/docs/mcp-tools/search) tool directly.
